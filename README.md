# Netflix Content Segmentation Using Clustering

## Project Overview
This project performs unsupervised machine learning on Netflix Movies and TV Shows dataset to segment content into meaningful clusters.

## Objective
To group Netflix content based on:
- Movie Duration
- TV Seasons
- Content Age
- Content Type

## Techniques Used
- Data Cleaning & Preprocessing
- Feature Engineering
- StandardScaler
- PCA (Dimensionality Reduction)
- KMeans Clustering
- Agglomerative Clustering
- GridSearchCV (Hyperparameter Tuning)
- Silhouette Score Evaluation

## Best Model
Optimized Agglomerative Clustering  
Silhouette Score: 0.7476

## Deployment Model
Optimized KMeans Model

## Business Impact
- Content Segmentation
- Improved Recommendation System
- Targeted Marketing Strategy
- Data-driven Content Planning
